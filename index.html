This app needs a Supabase project.

Once you paste your Project URL and publishable key into config.js, everything below turns on: real sign-up, posts, stories, reels, chat and notifications.

  1. Create a free project at supabase.com
  2. Run supabase-schema.sql, then supabase-upgrade.sql, then supabase-v2.sql
  3. Go to Settings → API Keys and copy the publishable key
  4. Paste it into config.js and reload
