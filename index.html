Connect your backend to go live

This app needs a Supabase project.

Once you paste your Project URL and anon public key into config.js, everything below turns on: real sign-up, real posts shared between people, photos, likes, comments, follows, chat and notifications.

  1. Create a free project at supabase.com
  2. Open SQL Editor and run supabase-schema.sql
  3. Go to Settings → API and copy the two keys
  4. Paste them into config.js and reload
